# Software Engineering Keywords

General software engineering vocabulary, organized by what a recruiter
searches and an ATS indexes. Use this file when the resume's strongest
signal is "software engineer" without further specialization (otherwise
prefer [backend.md](./backend.md), [frontend.md](./frontend.md),
[ai-ml.md](./ai-ml.md), etc.).

**Usage:** during workflow step 9, gap-analyze the resume against this
file. Only re-word an existing bullet to surface a missing keyword **if
the user has the underlying experience**. See
[rewrite-rules.md](../rewrite-rules.md) §7.

## Notes

- This file is intentionally **broad and shallow**. For role-specific
  depth, branch to the domain files (backend, frontend, ai-ml, etc.).
- The lists above are alphabetical-ish, not ranked. Recruiter prevalence
  varies by region, year, and seniority — don't ship a resume that lists
  every term. Pick the 8–12 the user actually has and group them.
