# Frontend Keywords

Vocabulary for frontend, full-stack (frontend-heavy), and UI engineer
resumes. Used in workflow step 9 when the target is frontend-shaped.

**Usage:** add keywords **only when supported by the user's experience**.
See [rewrite-rules.md](../rewrite-rules.md) §7.

For adjacent roles, branch:
- Server / API / DB depth → [backend.md](./backend.md)
- Mobile (iOS/Android native) → keep this file's web parts, add platform
  terms inline (`Swift`, `SwiftUI`, `Kotlin`, `Jetpack Compose`)
